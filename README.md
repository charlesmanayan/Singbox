# Triple C Karaoke

Triple C Karaoke is an Android karaoke player for Android TV and Android phones.

## Download and install

1. Download **TripleC-Karaoke-1.6.6.apk** from this repository.
2. On your Android TV or phone, allow installs from the browser or file manager you used to download the APK.
3. Open the downloaded APK and choose **Install**.
4. Open Triple C Karaoke and grant the requested media/storage permissions when you choose a song folder or install the Singbox library.

## Features

- MIDI playback with SoundFont support
- MP3 and MP4 playback
- Unified song search and reservation queue
- Spoken number keypad
- Custom BGV video backgrounds and lyric styles
- Wi-Fi browser/Android remote control with QR pairing
- Android TV D-pad and touchscreen support
- Microphone monitoring controls
- Song number, key, tempo, and volume controls

## Singbox library

The APK does not include songs, background videos, or SoundFonts. Install or select your own Singbox-compatible library after opening the app. Keep a backup of your personal library before changing folders or updating files.

## Requirements

- Android phone or Android TV
- Sufficient free storage for the APK and optional media library
- A local Wi-Fi network for remote control

## Version

Current APK: **1.6.6** (version code 114)

## Notes

This repository contains the installable APK only. It does not include the application source code, song library, BGV videos, or personal media.
